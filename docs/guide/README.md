# Termic+ guides

These pages explain the features Termic+ adds on top of upstream Termic, with
a short walkthrough for each. They assume Termic+ is installed (see
[Build it](../../README.md#build-it)) and that you have added at least one git
repository as a project.

| Guide | Covers |
| --- | --- |
| [Subagents](subagents.md) | Watching the subagents a `claude` tab starts |
| [Keep agents running](keep-agents-running.md) | Agents that survive quitting and updating the app |
| [Interface tour](interface.md) | The redesigned sidebar, title bar, tabs, footer and right panel |
| [Code intelligence](code-intelligence.md) | Rename symbol, format document and code actions |
| [File explorer](file-explorer.md) | The All files filter, new file buttons and keyboard moves in the right panel |
| [Zed keymap](zed-keymap.md) | Zed's editor keys in the built-in editor |
| [Workspaces](workspaces.md) | Tasks, worktrees and profiles |

Shortcuts are written with macOS keys. On Linux and Windows, `Cmd` is `Ctrl`.
Every shortcut can be changed in Settings > Shortcuts.
